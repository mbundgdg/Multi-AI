- [ ] **Step 1: Add failing state-machine tests**

- `start()` changes status to `playing`.
- `move(-1)` and `move(1)` change active x only while playing.
- `rotate(1)` changes rotation when legal.
- `togglePause()` prevents `tick`, `move`, `rotate`, `softDrop`, `hardDrop`, and `hold` from changing the snapshot.
- First `hold()` stores the active type, advances to `next`, and sets `canHold` false.
- Second `hold()` before lock does nothing.
- After locking, `canHold` resets to true.
- `softDrop()` adds 1 point per successful row.
- `hardDrop()` adds 2 points per row and locks immediately.
- A completed line increases `lines` and score.
- `restart()` resets score, lines, level, hold, and board, then sets status to `playing`.
- Repeated hard drops eventually reach `gameover`.
- `snapshot()` returns copies; mutating a returned board must not mutate engine state.

Use deterministic seed `1` for integration tests. Avoid timers and real time.

- [ ] **Step 3: Implement `createGame(seed?: number)`**

Required internal state:

```ts
interface InternalState {
  board: Cell[][];
  active: ActivePiece | null;
  next: TetrominoType;
  hold: TetrominoType | null;
  canHold: boolean;
  score: number;
  lines: number;
  level: number;
  status: GameStatus;
  gravityAccumulator: number;
  random: () => number;
  queue: TetrominoType[];
}
```

Required algorithms:

- `refillQueue()` appends `createBag(random)` until at least 2 entries exist.
- `spawn(type)` creates `{ type, rotation: 0, x: 3, y: 0 }`; if it collides, set `gameover` and `active = null`.
- `spawnNext()` takes `queue.shift()`, updates `next` to the new first queue item, then spawns the taken type.
- `lockPiece()` writes active cells to the board, sets `active = null`, checks hidden-area top-out, clears lines, updates score/lines/level, sets `canHold = true`, then spawns the next piece.
- `tick(deltaMs)` ignores non-finite or non-positive deltas, caps a single tick at 1000ms, accumulates gravity, and processes gravity steps without using `setTimeout`.
- `softDrop()` calls a one-row downward move; on failure it locks.
- `hardDrop()` uses `dropDistance`, adds `distance * 2`, moves to the landing row, and locks.
- `hold()` follows the spec and never allows two holds before a lock.
- `togglePause()` only toggles between `playing` and `paused`.
- `restart()` creates a fresh board and queue, resets all counters and hold state, and enters `playing`.
- `snapshot()` deep-copies the board and active piece; `ghostY` is `active.y + dropDistance(...)` or `null`.
