# Docs 目录说明

本目录保存项目协作与验收资料。

| 文件 | 作用 | 主要内容 |
| --- | --- | --- |
| `00.todo.md` | 当前任务计划与评审记录 | 阶段任务、角色分工、检查项、测试结果、构建产物、未完成项和最终评审。 |
| `01.history.md` | 项目经验记录 | 按角色追加实施经验、问题根因、修正方式与可复用教训。 |
| `02.Multi-AI.md` | 协同架构基线 | Orchestrator/Implementer 的职责、闭环流程、契约冻结、失败回退、验收边界与交付模板。 |

后续设计文档和实现计划也会在本目录中登记，避免文档散落。
