# Docs 目录说明

本目录保存项目协作与验收资料。

| 文件 | 作用 | 主要内容 |
| --- | --- | --- |
| `00.todo.md` | 当前任务计划与评审记录 | 阶段任务、角色分工、检查项、测试结果、构建产物、未完成项和最终评审。 |
| `01.history.md` | 项目经验记录 | 按角色追加实施经验、问题根因、修正方式与可复用教训。 |
| `02.Multi-AI_cli.md` | CLI 协作架构基线 | Orchestrator/Implementer 职责、终端会话、统一 Supervisor 事件桥、契约冻结、异常回退与交付模板。 |
| `02.Multi-AI_paseo.md` | Paseo 历史架构 | 过往 Paseo agent/workspace 管理方式，保留供回溯，不是当前默认路径。 |

统一 CLI Supervisor 源码、测试与用法位于仓库根目录 `02.Multi-AI/`。
